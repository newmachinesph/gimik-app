## Fixes delivered

Onboarding now sends editable fields to the API and waits for required photo uploads. Profile saves report failure when the server refuses. New uploads immediately register their photo IDs, so reorder/delete work without a refresh. The tighter Edit Profile spacing remains in place.

The backend now signs R2 requests against the S3 API endpoint, validates actual image bytes and converts supported photos to upright WebP. Conversion strips EXIF/GPS and handles embedded color profiles; GIF and other multi-frame inputs become still images. Canonical profile keys make upload-claim retries idempotent. Journal photos use the same conversion and reject another user's object keys.

The app subscribes to invite/friend events as well as messages, refreshes when foregrounded, and restores sessions for cold deep links. Chat navigation waits for real server IDs; inviting someone no longer invents a conversation before acceptance. Opening a thread loads its history. Same-account refreshes retain catalog ID mappings, including custom activities with no slug.

Other public profiles no longer display age zero or fabricated membership dates. Journal screens load saved entries, upload attached photos, and keep the draft if saving fails. Group creation and joining wait for server results.

## Open release blockers

1. **Private media is publicly reachable.** Production uses the same R2 bucket for catalog artwork and personal media. A request to the unsigned CDN URL of the synthetic QA journal photo returned HTTP 200. Signed URLs alone do not make this bucket private. Create a separate private media bucket, migrate existing profile/journal objects with a verified manifest and rollback plan, then change only the user-media configuration. Do not disable the public catalog bucket. Infrastructure migration needs approval.
2. **Shared web links do not work without the app.** Production returned 404 for `/want/aquarium-touring`, `/join/qa-invalid-token`, and `/.well-known/assetlinks.json`. The mobile app generates these HTTPS shares. Add fallback routes and configure Android verification using the production signing certificate; iOS universal links require the Apple team/app association. Store destinations must be confirmed before publishing download links.

The Edit Profile keyboard can cover lower fields until the user scrolls. Text entry and saving worked, but keyboard-aware scrolling still needs a focused UI pass.
